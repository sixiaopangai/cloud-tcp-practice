# 提交说明

## 一、启动顺序

1. 登录云服务器，进入 `cloud_server` 目录，编译并运行服务器：

   ```bash
   gcc pth_server.c -o server -lpthread
   ./server
   ```

2. 在 Ubuntu 虚拟机中进入 `device_client` 目录，编译并运行设备端：

   ```bash
   gcc client.c -o client -lpthread
   ./client <SERVER_PUBLIC_IP> 9999
   ```

3. 在手机端安装本工程生成的无广告 TCP 调试助手，或使用老师提供的网络调试助手，以 TCP Client 模式连接云服务器。

## 二、手机端配置

- 模式：`TCP Client`
- 地址：`<SERVER_PUBLIC_IP>`
- 端口：`9999`
- 发送内容：`openled` 或 `closeled`

把 `<SERVER_PUBLIC_IP>` 替换成你自己的云服务器公网 IP，不要把真实 IP 提交到公开仓库。

## 三、截图清单

老师给的图片只是示例，提交时建议截自己的运行结果：

- 云服务器终端：服务器启动成功
- 云服务器终端：显示手机端和 Ubuntu 设备端接入
- 云服务器终端：显示收到 `openled` / `closeled` 并转发
- Ubuntu 终端：设备端连接成功
- Ubuntu 终端：收到 `openled` 后打印 LED 打开并发送 `LED:ON`
- Ubuntu 终端：收到 `closeled` 后打印 LED 关闭并发送 `LED:OFF`
- 手机端：连接服务器成功
- 手机端：发送 `openled` / `closeled` 并收到 `LED:ON` / `LED:OFF`

## 四、常见问题

| 问题 | 处理方式 |
| --- | --- |
| 手机连不上服务器 | 检查云服务器防火墙是否开放 `9999/TCP`，检查服务器程序是否正在运行 |
| Ubuntu 设备端连接失败 | 检查运行 `./client <SERVER_PUBLIC_IP> 9999` 时填写的公网 IP 是否正确 |
| `bind: Address already in use` | 云服务器执行 `killall server` 后重新运行 |
| 手机发了指令但收不到状态 | 确认 Ubuntu 设备端也已连接到同一台服务器 |
| 编译提示找不到 pthread | 编译命令需要加 `-lpthread` |
